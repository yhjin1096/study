실험 6 ESKF — 에러 상태는 늘 원점 근처에 있다 원문에 없는 추가 요소 · §5 식 (43)(57)(58)(60) 보조

위 패널은 nominal 상태 x̂(파랑), 참값(회색), 관측(점)이다. 아래 패널이 에러 상태 δx̂로, prediction에서는 항상 0이고(식 57의 "Always 0") correction에서만 값이 생겼다가 reset으로 즉시 0으로 돌아간다(식 60). 비선형성을 키워도 nominal은 크게 휘지만 δx̂는 계속 작은 값에 머무는 것 — 이것이 "에러 상태는 항상 원점 근처라 선형화가 쉽다"는 §5 도입부의 주장이다.

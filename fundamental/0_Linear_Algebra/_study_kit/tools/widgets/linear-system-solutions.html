실험 1 Ax = b — 행 그림과 열 그림 원문에 없는 추가 요소

같은 2×2 시스템을 두 관점으로 본다. 왼쪽 행 그림은 각 방정식을 직선으로 보고 교점을 찾는 것이고, 오른쪽 열 그림은 식 (12)처럼 a₁x₁ + a₂x₂ = b — 열벡터의 선형결합으로 b를 만드는 것이다. det A = 0이 되도록 슬라이더를 맞춰 보면 1.6절이 말하는 두 경우 (해 없음 / 무수히 많은 해)가 갈리는 이유가 열 그림에서 한눈에 보인다 — b가 Col A 안에 있는가(식 34).

실험 7 등각 회전 — q⊗x 와 x⊗q* 가 하는 일을 두 평면으로 나눠 보기 원문에 없는 추가 요소

축을 u = z로 두면 ℝ⁴는 서로 직교하는 두 평면 A = span{1, k}와 B = span{i, j}로 쪼개진다. 왼쪽 곱 q⊗x는 두 평면을 같은 방향으로 θ/2씩 돌리고(등각), 오른쪽 곱 x⊗q*는 A는 −θ/2, B는 +θ/2로 돌린다. 그래서 둘을 겹치면 A는 0°, B는 θ — 이것이 q⊗x⊗q*가 3차원 회전이 되는 이유다(2.8절).

x q ⊗ x (왼쪽 곱) x ⊗ q* (오른쪽 곱) q ⊗ x ⊗ q*

실험 11 세 가지 상태 — nominal 은 흘러가고, error 가 그것을 붙잡는다 원문에 없는 추가 요소

한 축(yaw)만 있는 IMU로 식 (262)의 nominal 적분과 식 (263)·(268)의 error 상태 전파를 그대로 돌린다. 상태는 (θ, b), 에러는 (δθ, δb), Fx = [[1, −Δt], [0, 1]], Qi = diag(σω²Δt², σbw²Δt)다. 가끔 들어오는 절대 방위 관측으로 (272) 보정 → (280) 주입 → (282) 리셋을 수행한다. nominal 만 쌓으면(점선) bias 때문에 계속 흘러가지만, error 상태를 주입한 추정치는 참값을 따라간다.

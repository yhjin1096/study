## 추천 읽기 순서

24쪽으로 짧지만 **네 가지 알고리즘이 같은 뼈대를 반복**한다.
(에러 정의 → 최소제곱 → 자코비안 → GN 루프) 4.3절에서 그 뼈대를 익히면 나머지는 변주다.

1. **1~3장 + 실험 1** — 무엇이 문제인가. 예제 데이터를 눈에 익혀 둘 것
2. **4.1 + 실험 2** — SVD 닫힌 해. **이 노트에서 유일하게 반복이 없는 대목**이다.
   (3)→(4)→(9)→SVD→(26) 의 흐름과 (27) 보정의 이유
3. **4.2 + 실험 3** — 왜 반복이 필요한가. 수렴 반경을 꼭 만져 볼 것
4. **4.3 + 실험 4** — GN 뼈대. 이후 모든 절이 이 틀을 그대로 쓴다
5. **4.3.1 + 실험 5** — $so(3)$ 좌섭동. 3_Lie_Theory·6_Errors 스터디와 이어진다
6. **5장 + 실험 6·7·8** — point-to-plane. **법선을 어떻게 구하느냐가 성패를 가른다**
7. **6장 + 실험 9** — GICP 의 확률 정식화. (74)→(78)→(81) 만 따라가면 된다
8. **6.1~6.3 + 실험 10·11** — 공분산 세 가지
9. **6.4 + 실험 12** — 하나의 루프로 셋을 모두 돌려 확인. 이 노트의 결론

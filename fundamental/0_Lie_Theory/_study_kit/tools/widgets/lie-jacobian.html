실험 3 Lie Group 자코비안 — 정의 (8) 을 τ → 0 으로 수렴시켜 보기 원문에 없는 추가 요소

식 (8)은 벡터공간의 미분 정의 (6)에서 +, −를 ⊕, ⊖로 바꾼 것이다. 여기서는 SO(3) 위의 함수 f(R) = R·R(회전을 두 번 적용)의 자코비안을 (8)의 정의 그대로 차분으로 계산하고, τ 를 줄여 가며 얼마나 정확해지는지를 본다. 비교 대상은 두 가지다 — 해석적 자코비안(f(R⊕τ) = R·R·Exp(AdR⁻¹τ + τ) 에서 얻는 J = AdR⁻¹ + I)과, 매니폴드를 무시하고 행렬 성분을 그냥 뺀 (6)식 방식이다. 후자는 수렴하지 않는다 — 결과가 SO(3) 위에 없기 때문이다.

식 (8) 정의 — ⊕/⊖ 사용 식 (6) 방식 — 행렬 성분을 그냥 뺌 기울기 1 기준선

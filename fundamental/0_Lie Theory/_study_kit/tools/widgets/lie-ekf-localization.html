실험 10 on-manifold EKF — ⊕ 를 그냥 + 로 바꾸면 어떻게 되는가 원문에 없는 추가 요소

식 (81)~(83)을 SE(2)에서 그대로 돌린다 (평면에 그리기 위해 SE(3) 대신 SE(2)를 썼다). motion model x ← x ⊕ u·dt, measurement y = x⁻¹b + v, 그리고 (82)의 F, G와 (83)의 H는 Df/Dx 정의로 계산한다. 같은 데이터를 두 번 돌린다 — 하나는 ⊕/⊖ 를 제대로 쓴 것, 다른 하나는 상태를 그냥 (x, y, θ) 벡터로 보고 + 로 더한 것이다. 입력 u가 몸체 좌표계에서 주어지므로, 단순 덧셈은 방향이 돌아간 만큼 어긋난다.

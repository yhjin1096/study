실험 1 tile 을 키우면 arithmetic intensity가 오르고 occupancy 가 죽는다 책 15.2 · 15.7절 (p.351, 363) 재현

block tile bM·bN 과 bK, block 당 thread 수를 바꿔 본다. 위 막대가 arithmetic intensity 이고 점선이 H100 임계값 20 FLOP/B 다 — 이 선을 넘어야 compute-bound 다. 아래 세 막대가 shared memory · thread 당 register · occupancy 다. bM·bN 을 키우면 arithmetic intensity가 오르지만 register 가 폭증하고, bK 는 arithmetic intensity를 전혀 바꾸지 않으면서 shared memory 만 먹는다.

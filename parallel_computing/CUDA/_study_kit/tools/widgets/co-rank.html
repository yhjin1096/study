rank k 를 정하고 한 step 을 눌러 본다. 파란 막대가 i_low·i, 초록 막대가 j_low·j 이고 아래 C 에서 굵은 칸이 이번 thread 가 만들 출력이다. 두 조건 A[i-1] <= B[j] 와 B[j-1] < A[i] 가 모두 만족되면 종료한다. 등호가 한쪽에만 있는 것이 stability 이고, 그것이 k=6 에서 (5,1) 과 (4,2) 의 tie 를 끊는다.

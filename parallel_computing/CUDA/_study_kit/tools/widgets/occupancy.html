실험 1 Occupancy — 무엇이 발목을 잡는가 책 4.7절 (p.85~86) 의 수치 예를 재현

block 크기와 thread 당 register 수를 바꿔 본다. occupancy 는 세 제약(thread slot · block slot · register) 중 가장 빡빡한 것이 정한다. 위 곡선은 지금 register 수에서 block 크기만 바꿨을 때의 occupancy 이고, 아래 막대는 각 제약이 허용하는 block 수다. 가장 짧은 막대가 범인이다.

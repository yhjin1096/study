가로축은 arithmetic intensity(FLOP/B), 세로축은 도달 가능한 throughput(TFLOPS)이다. 꺾인 지붕선이 하드웨어 한계로, 왼쪽 빗변은 memory bandwidth가, 오른쪽 평지는 peak 연산 성능이 정한다. TILE_WIDTH 를 키우면 matmul 의 점이 빗변을 타고 오른쪽 위로 올라간다.

왼쪽은 scoring matrix 이고 색이 tile anti-diagonal 번호 d, 굵은 선이 tile 경계다. 오른쪽은 tile 하나를 계산할 때 반복마다 활성인 thread 수 다. 사각 tile 은 2n-1 번 반복하며 활성 thread 가 1→n→1 로 변하고, hypertile 은 n 번 반복하며 언제나 n 개가 활성이다. 총 work 는 둘 다 n² 로 같다 — 같은 일을 몇 번에 나눠 하느냐만 다르다.
